# Wireframes — 捐血勇士 (Blood Hero)

> 以 375×812px (iPhone SE/標準) 為基準，所有尺寸以比例描述。
> 品牌色：紅色系 #E53935，輔色：白 #FFFFFF，淺灰 #F5F5F5，深灰 #333333

---

### 互動行為
- **Email 輸入框**: focus 時邊框變品牌紅，即時驗證 email 格式

- **登入按鈕**: 點擊後顯示 loading spinner；disabled 狀態（欄位未填）時降低透明度
- **Google 登入**: 點擊跳轉 Google OAuth
- **忘記密碼**: 點擊彈出 Bottom Sheet 輸入 email 發送重設信
- **立即註冊**: 導航至註冊頁

- **取消 (✕)**: 若已填寫內容，彈出確認對話框 "確定放棄？已填寫的內容將不會儲存"

- **地點輸入**: 自動完成下拉，顯示歷史地點（最近使用優先）和捐血站列表
- **備註**: 自動增高至內容長度，最大 200 字
- **儲存按鈕**: 
  - 日期 + 類型皆填寫後才啟用
  - 點擊後: 按鈕變 loading → API 呼叫 → 成功畫面滑入
  - 失敗時: Toast 提示 "儲存失敗，請重試"
- **成功畫面**: Checkmark 有 Lottie 動畫，下次可捐日期自動計算並顯示

## 通用 UI 規範

### 字體大小
| 元素 | 大小 | 粗細 |
|------|------|------|
| 頁面標題 | 20px | Bold |
| 區塊標題 | 16px | SemiBold |
| 正文 | 14px | Regular |
| 輔助文字 | 12px | Regular |
| 統計數字 | 24px | Bold |
| 按鈕文字 | 16px | SemiBold |

### 間距
| 區域 | 間距 |
|------|------|
| 頁面邊距 | 左右 20px |
| 區塊間距 | 24px |
| 卡片內邊距 | 16px |
| 元素間距 | 12px |
| 輸入框間距 | 16px |

### 圓角
| 元素 | 圓角 |
|------|------|
| 卡片 | 12-16px |
| 按鈕（膠囊） | 25px |
| 輸入框 | 12px |
| 頭像 | 50%（圓形） |
| Bottom Sheet | 頂部 20px |

### 動畫
| 行為 | 動畫 | 時長 |
|------|------|------|
| 頁面切換 | Slide from right | 300ms |
| Modal/Sheet | Slide from bottom | 250ms |
| 按鈕點擊 | Scale 0.95→1.0 | 150ms |
| 數字計數 | Count up | 800ms |
| 成功提示 | Lottie checkmark | 500ms |
| Tab 切換 | Fade in/out | 200ms |
